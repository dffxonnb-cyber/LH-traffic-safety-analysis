# QGIS 제출 가이드

**목적**: 공모전 필수 요구사항인 **QGIS 파일 제출**에 대응하기 위한 절차·산출물·체크리스트를 정리한다.

---

## 1. 제출 대상

| 유형 | 확장자 | 설명 |
|------|--------|------|
| **QGIS 프로젝트** | `.qgz` | 레이어 구성, 스타일, 맵 캔버스가 저장된 프로젝트 파일 |
| **레이어 파일** | GeoJSON, Shapefile 등 | QGIS에서 사용한 공간 데이터 (프로젝트와 함께 압축 제출 시 재현성 확보) |

---

## 2. 진행 절차

### 2-1. Python/노트북에서 GeoJSON 산출

- 격자 위험도, 고위험 격자, 토지이용·인프라 결과를 **GeoJSON**으로 저장
- **CRS**: EPSG:4326 (WGS84)로 통일 — QGIS 기본 좌표계와 호환
- 저장 경로 예: `data/통합_데이터/QGIS_제출용/`

### 2-2. QGIS에서 프로젝트 구성

1. QGIS에서 GeoJSON 레이어 추가
2. 위험도 구간별 색상, 레이블 등 시각화 스타일 적용
3. 인쇄 레이아웃(맵 캔버스)으로 지도 구성
4. `.qgz` 프로젝트 파일로 저장

### 2-3. 제출 파일 패키징

- `.qgz` 프로젝트 파일
- 사용한 GeoJSON·Shapefile 등 레이어 파일 (프로젝트 내 경로 상대경로 권장)
- 압축 후 제출

## 4. Python → QGIS 연동 시 유의사항

- **GeoPandas**로 GeoJSON 저장 시 `to_file(..., driver='GeoJSON')` 사용
- 좌표계: `gdf.to_crs(4326)` 으로 WGS84 변환
- 파일명·경로: 한글·특수문자 최소화 (호환성)
