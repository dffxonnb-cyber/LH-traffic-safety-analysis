# 파생 변수 계획 — 보유 데이터·외부 자료 기반

**목표**: 프로젝트에서 보유한 **토지 데이터**, **도로망·교통량·혼잡 데이터**와, **LH 내집어디·공공데이터포털** 등 분석에 도움 되는 외부 자료를 활용해 **파생 변수**를 만들고, 이를 토대로 분석 및 문서 작성에 활용한다.

**분석 대상 지역**: 4개 시·구(성남·화성·하남·송파), 적용대상지 하남교산. 남북 구분·교통축 등은 [지역_도메인_요약.md](지역_도메인_요약.md) 참고.

보유 데이터만으로는 부족한 부분을 보완하거나, 파생 변수 산출·검증에 쓸 수 있는 외부 자료를 정리한다.

| 항목 | 내용 |
|------|------|
| **URL** | https://wherehome.lh.or.kr/lhmap.do |
| **제공 정보** | 3기신도시·지구별 토지이용계획도, 연속지적도, 법정동경계도, 공시지가. 용도(단독/공동주택, 상업·업무, 산업·유통, 교육, 공공청사, 기타). 지구정보(면적, 사업비, 사업일정), 보상·단지조성·주택건설·공급/회수 정보. 공급유형(공공분양/임대), 공급면적(60㎡ 이하 등), 공급시기. 블록별 면적·인구수·세대수·용적율 등. |

## 3. 보유·외부 자료로 만드는 파생 변수

아래 파생 변수는 **보유 데이터**만으로 만들 수 있는 것과 **외부 자료**를 보완해 만드는 것으로 구분했다.

| 파생 변수 | 필요한 데이터 | 산출 방법·비고 |
|-----------|----------------|----------------|
| **토지·용도** | 22·23 토지이용계획도 (보유) | 격자와 토지이용 폴리곤 결합 → 용도별(도로·주거·상업·산업·교육 등) 면적·비율. 06 노트북의 도로 격자 여부와 동일 계열. |
| | + LH 내집어디 (외부) | 용도 세분화·블록 정보로 혼합도·공급 단계 보강 가능. |
| **도로·교통** | 08 상세도로망, 09·10·11·12 (보유) | 도로망 road_rank와 격자 결합 → 국도·지방도·고속도 접근 여부. 링크별 속도·교통량·혼잡을 격자에 집계 → 격자별 평균속도·교통량·혼잡강도. |
| **인프라 부족도** | 18 횡단보도, 20 CCTV, 격자 (보유) | 격자 중심 반경 500m 내 시설 수 → 부족도(0 또는 하위 비율). 06 노트북과 동일. |
| **시설 밀집도** | 14~17 시설, 격자 (보유) | 격자/반경 내 어린이집·학교·유치원 수·수용인원 → 통학로 후보 격자, 밀집도 지표. |
| **인구·연령** | 03 성연령별 거주인구 격자 (보유) | 격자별 이미 보유. 연령대 비율, 특정 연령 인구 수 등 파생 가능. |
| **접근성** | 격자 좌표 + 경기교통정보센터·도로중심선 (외부) | 주요역·도심까지 대중교통 시간·거리 → 격자별 접근성 점수(수동·반자동). |
| **유동·시간대** | 공공데이터포털 유동인구 (외부) | 행정동/시군 시간대별 유동인구 → 격자 매핑 가능 시 등하교·통근 시간대 고유동 격자. |
| **공급·입주 단계** | LH 내집어디 (외부) | 지구별 공급시기·블록 정보 → 입주 단계·성숙도 보조 지표(문헌·수동 정리와 병행). |

## 4. 정량 기준 (해석 시 사용)

파생 변수로 "밀집", "고부하", "접근성 좋음" 등을 쓸 때, 아래처럼 기준을 두면 재현·논의에 유리하다.

| 용어 | 정량 기준(안) | 비고 |
|------|----------------|------|
| 시설 밀집 | 격자 반경 500m 내 시설(어린이집·학교·유치원 등) 합계가 전체 격자 상위 20% 또는 3개 이상 | 데이터 분포에 따라 조정 |
| 접근성 좋음 | 주요역까지 대중교통 소요시간이 해당 시·구 하위 25% | 외부 데이터 수집 후 구체화 |
| 고부하(교통) | 격자 연동 교통량·혼잡이 전일 평균 대비 상위 25% | 09·10·11·12 격자 연동 후 |
| 인프라 부족 | 반경 500m 내 횡단보도·CCTV 0 또는 하위 20% | 06 노트북 정의 유지 |

## 5. 문서·분석 활용

- **보고서·문서**: 위 파생 변수(토지 용도, 도로·교통 부하, 인프라 부족, 시설 밀집, 인구, 접근성 등)를 **지역별·격자별**로 요약해, "어떤 지역이 어떤 특성을 가지는지"를 숫자·지도로 제시한다.
- **기존 분석과의 연결**: 격자 위험도(04·05)·인프라 부족(06) 결과와 파생 변수를 결합해, 고위험 격자가 **어떤 토지·교통·인구 특성**과 맞는지 설명할 수 있다.
- **외부 자료**: LH 내집어디는 토지이용·공급 정보 보강용, 공공데이터포털은 접근성·유동인구·교통량 보완용으로 참고하고, 수집 가능한 항목부터 파생 변수에 반영한다.
