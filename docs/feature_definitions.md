# EDA 파생변수 정의 및 논리

각 EDA 노트북에서 산출하는 파생변수의 정의, 계산 방식, 활용 논리를 정리합니다.

---

## 01 토지이용 EDA

### 파생변수
| 변수 | 정의 | 계산 방식 |
|------|------|-----------|
| 도로_비율 | 격자 내 도로 면적 비율 | blockType='도로' intersect 비중 |
| 주거_비율 | 공동주택·단독주택 비율 | blockType 합산 비중 |
| 상업_비율 | 상업시설 비율 | blockType='상업시설' 비중 |
| 학교_비율 | 초·중·고·학교 비율 | blockType 합산 비중 |
| 녹지_비율 | 녹지·공원·경관녹지 비율 | blockType 합산 비중 |
| 도로_격자_여부 | 도로가 포함된 격자 여부 | 도로_비율 > 0 → 1 |

### 논리·유의미성
- **도로 격자**: 교통사고는 도로에서 발생 → 도로_비율·도로_격자_여부는 위험 격자 식별의 기본 조건
- **주거·학교**: 미성년자 거주·통학 밀집구역은 노출도↑ → 위험도 모델의 입력변수
- **녹지**: 공원·녹지 비율이 높으면 통행 패턴이 달라질 수 있음 → 보조 지표
- **산출물**: `격자_토지이용_파생변수_4시구.csv`, `격자_토지이용_파생변수_하남교산.csv`

## 02 도로망·교통량 EDA

### 파생변수
| 변수 | 정의 | 계산 방식 |
|------|------|-----------|
| velocity_mean | 격자 평균 속도(km/h) | API AADT·속도 데이터 |
| AADT_mean | 일평균 교통량 | API |
| 고부하_여부 | 교통량 상위 25% 여부 | AADT_mean ≥ Q75 |
| velocity_구간 | 속도 구간(저속~초고속) | 0–30, 30–50, 50–70, 70+ km/h |

### 논리·유의미성
- **교통량·속도**: 고부하·고속 구간은 충돌 에너지↑, 정지 거리↑ → 사고 심각도·발생 확률과 상관
- **고부하_여부**: 상위 25% 구간을 우선 점검·시설 개선 대상으로 활용
- **산출물**: `격자_교통량_파생변수_4시구.csv` (격자 gid 기준, 08 도로망+09·10 연동 시) 또는 `격자_교통량_파생변수.csv` (grid_id 기준, 연동 미실시 시)

## 03 하남교산 유사격자 매칭

### 파생변수
| 변수 | 정의 | 계산 방식 |
|------|------|-----------|
| 하남_gid | 하남교산 격자 ID | - |
| 유사_4시구_gid | 토지 유사한 4개 시·구 격자 ID | 코사인 유사도 argmax |
| 유사도 | 토지 blockType 벡터 유사도 | 0~1 |
| 유사_고위험_여부 | 매칭된 4시·구 격자가 고위험(상위20%)이면 1 | 상위20 gid 집합에 포함 여부 |

### 논리·유의미성
- **유사도 매칭**: 지형·토지이용 기반으로 4개 신도시와 하남교산 격자 매칭 → 사고 이력이 없는 적용대상지에 위험 정보 전이
- **유사_고위험_여부**: 4시·구에서 위험했던 격자와 토지 유사한 하남 격자는 선제적 개선 대상 후보
- **산출물**: `하남교산_유사격자_매칭.csv`

## 04 시간대별 노출도 EDA

### 파생변수
| 변수 | 정의 | 계산 방식 |
|------|------|-----------|
| 통학로_노출_여부 | 학교·유치원·어린이집 500m 버퍼 내 격자 여부 | 시설 포인트 buffer(0.005°) sjoin |
| 등하교_유동_평균 | 6~9시, 14~17시 유동인구 평균 | 시간대별_방문인구 → 격자 sjoin 후 mean |

### 논리·유의미성
- **등하교 사고 비율(35.8%, 미성년자 기준)**: 등하교 시간대 노출 격자를 별도 지표로 관리하는 근거
- **통학로_노출_여부**: 학교 주변 500m는 미성년자 통행 밀집 → 스쿨존·횡단보도 개선 우선순위
- **등하교_유동_평균**: 유동인구가 높은 격자는 노출도↑ → 위험도 모델의 노출 변수
- **산출물**: `격자_시간대노출_파생변수.csv`

## 05 기상·환경 EDA

### 파생변수
| 변수 | 정의 | 계산 방식 |
|------|------|-----------|
| 악천후_여부 | 비·눈 또는 노면 젖음/습기 여부 | weather, road_sttus 문자열 매칭 |
| 야간_여부 | 18시~06시 여부 | hour 파싱 후 범위 판별 |

### 논리·유의미성
- **악천후(6.2%, 미성년자 기준)**: 비·젖은 노면은 제동거리↑, 시인성↓ → 요인 분석 시 기상 변수로 활용
- **야간(37.1%, 미성년자 기준)**: 야간은 시인성·인지 저하 → 등하교 외 시간대 사고 비중 파악
- **산출물**: `전처리_교통사고_미성년자_기상파생.geojson` (사고 건별 플래그 추가)

## 06 API 데이터 격자 연동 (인사이트\_분석/01)

> 실행 파일: `analysis_pipeline/01_grid_api_integration.ipynb`  
> 산출물: `격자_최종통합.csv` (`격자_통합_파생변수.csv` + 아래 5개 컬럼 추가)

### 파생변수
| 변수 | 정의 | 원본 소스 | 계산 방식 |
|------|------|-----------|-----------|
| 미성년자_유동 | 격자 내 10세 미만·10~19세 유동인구 평균 | 성연령별_유동인구_100m격자.csv | m_10g_pop + w_10g_pop 합산 → 동일 격자 평균 → KDTree 최근접 매핑 |
| 노인_유동 | 격자 내 60대 이상 유동인구 평균 | 성연령별_유동인구_100m격자.csv | m_60g_pop + w_60g_pop 합산 → 동일 격자 평균 → KDTree 최근접 매핑 |
| acc_count | 격자 내 교통사고 건수 합산 | 교통사고_100m격자.csv | gid별 acc_count 합산 (희소 데이터 — 사고 발생 격자만 > 0) |
| FRIN_mean | 격자별 도로 마찰지수 평균 | grid_100m_export.csv | FRIN_CG 컬럼, 도로 없는 격자(=0) 제외 후 gid별 평균, EPSG:5179→WGS84 변환 |
| TI_mean | 격자별 도로 거칠기 지수 평균 | grid_100m_export.csv | TI_CG 컬럼, 동일 방식 |

### 매핑 방식
- **KDTree 최근접 매핑**: API 데이터의 lon/lat 좌표와 격자 centroid 좌표 간 최근접 매핑
- **최대 탐색 반경**: `max_dist_deg=0.0055` (약 500m)
- **FRIN/TI CRS**: 원본 좌표가 EPSG:5179(TM 좌표) → `pyproj`로 WGS84 변환 후 매핑

### 연동 성공률 (실질 연동 가능 격자 기준)
| 변수 | 기준 | 목표 |
|------|------|------|
| 미성년자_유동 | API 소스 격자 대비 | ≥ 80% |
| 노인_유동 | API 소스 격자 대비 | ≥ 80% |
| acc_count | 원본 사고 격자 매핑률 | 100% (희소 데이터) |
| FRIN_mean / TI_mean | 도로 격자(FRIN>0 or TI>0) 대비 | ≥ 80% |

### 활용
- `미성년자_유동`은 `05_정규화.ipynb`에서 **5번째 위험점수 지표**로 편입 (가중치 0.20)
- `노인_유동`은 `03_동시취약_시간대.ipynb`의 노인 취약 분석에서 참조
- `acc_count`는 격자 수준의 직접 사고 빈도 지표

## 통합 활용 흐름

```
01 토지(도로·주거·학교) ─┬─→ 격자별 용도 특성
02 교통량·속도          ─┼─→ 격자별 교통 부하
04 통학로·등하교 유동   ─┼─→ 격자별 노출도
06 API(유동·사고·FRIN)  ─┼─→ 격자별 실측 노출량·도로 상태
                         │
03 하남교산 매칭        ─┴─→ 4시·구 위험 정보 → 하남교산 적용
05 기상·야간            ───→ 사고 건별 요인(시계열·요인 분석용)
```

위 파생변수들을 격자 gid 기준으로 merge하면 **위험도 예측·우선순위 산정 모델**의 입력 데이터셋을 구성할 수 있습니다.
