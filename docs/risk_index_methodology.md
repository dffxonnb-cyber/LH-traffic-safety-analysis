# 위험지수 산출 근거

본 문서는 격자별 **위험점수**, **ARI(Accident Risk Index)**, **위험점수_정규화**의 정의와 산출 근거를 정리한 것입니다.  
관련 노트북: `04_집계_위험점수_ARI.ipynb`, `05_정규화.ipynb`

---

## 1. 위험점수 (원점수)

### 공식

```
위험점수 = 어린이보호구역_사고×1 + 스쿨존_다발지×2 + 미성년자_사고×1 + KSI×3
```

- **어린이보호구역_사고**: `격자내_어린이보호구역_어린이사고_건수`
- **스쿨존_다발지**: `격자내_스쿨존_다발지_개수`
- **미성년자_사고**: `격자내_미성년자_교통사고_건수`
- **KSI**: `격자별_KSI` (격자 내 미성년자 사망·중상 합계)

### 가중치 설정 근거

| 항목 | 계수 | 의도 |
|------|------|------|
| 어린이보호구역 사고 | 1 | 격자 내 발생 건수 그대로 반영 |
| 스쿨존 다발지 개수 | 2 | 다발지 1개를 “사고 2건에 상당하는 위험”으로 간주. 스쿨존은 지정 구역 단위이므로 건수와 단위가 달라 상대적 가중 부여 |
| 미성년자 교통사고 | 1 | 격자 내 미성년자 사고 건수 그대로 반영 |
| KSI(사망+중상) | 3 | 심각도가 높은 결과이므로 위험도 반영을 위해 가중. 도로교통법 시행규칙에서 KSI를 **사고심각성 대표 지표**(사망+중상)로 사용하는 것에 맞춰, 상대적으로 높은 가중을 둠[^1] |

위 가중치는 **공모전·분석 목적(미성년자 교통안전)** 에 맞춘 합리적 설정이며, 추후 문헌·전문가 검토 또는 민감도 분석으로 조정할 수 있습니다.  
스쿨존 다발지에 대한 단일 계수(×2)는 공식 지침에서 수치를 제시하지 않아, 본 분석에서 “다발지 1개 ≈ 사고 2건 상당”으로 보는 **상대적 가중**으로 적용한 것이다[^2].

### 시군구 가중치 (04 노트북)

- **적용 방식**: 격자별 **위험점수(원)** 를 산출한 뒤, 해당 격자가 속한 **시군구(gbn)** 의 가중치를 곱해 최종 **위험점수** 로 사용한다. (고위험 격자 Top10·저장 CSV는 이 시군구 가중 적용 위험점수 기준이다.)
- **가중치 산정**: **데이터 기반**으로, 시군구별 "격자당 평균 미성년자 교통사고 건수"를 구한 뒤, 전체 격자당 평균으로 나눈 비율을 사용한다. 사고 밀도가 높은 시군구일수록 1보다 큰 가중치가 부여된다.
- **구간 제한**: 가중치를 **0.8~1.2** 구간으로 제한해, 극단적 스케일 차이로 인한 왜곡을 줄였다.
- **정책 우선순위 미사용**: 특정 시·구에 수동으로 우선순위(예: 1.2배)를 주는 **정책 우선순위 테이블은 사용하지 않는다.** 시군구 간 상대적 위험도는 전적으로 데이터(격자당 사고 밀도 비율)로만 반영한다.
- **이유**: 03 EDA에서 시군구별 사고 건수·비율 차이가 큼을 보였으므로, 04에서 "어느 시군구가 상대적으로 위험한지"를 위험점수에 반영해, 결과 해석·우선순위 논의 시 일관되게 활용할 수 있도록 한 것이다.

## 2. ARI (Accident Risk Index)

### 공식

```
ARI = √(KSI² + 사고건수²) / 관측 연수
```

- **KSI**: 격자별 미성년자 사망·중상 합계 (`격자별_KSI`)
- **사고건수**: 격자 내 미성년자 교통사고 건수 (`격자내_미성년자_교통사고_건수`)
- **관측 연수**: 분석에 사용한 데이터의 연수 (`n_years`)

### 의도

- **심각도(KSI)** 와 **빈도(사고건수)** 를 동시에 반영하는 복합 지표입니다.
- √(KSI² + 사고건수²) 형태로 두 축을 결합한 뒤, 연수로 나누어 **연간 단위**의 위험도로 해석할 수 있도록 했습니다.
- **KSI(사망+중상)** 는 도로교통법 시행규칙 별표 8의2(어린이보호구역 무인 교통단속용 장비 설치 기준)에서 **교통사고 위험지수(ARI)** 산정 시 **사고심각성 대표 지표**로 사용된다[^1]. 본 프로젝트는 동일한 KSI 정의를 쓰되, 수식은 심각도와 빈도를 동시에 반영하는 형태(√(KSI²+사고건수²)/년)로 정의하였다.

## 3. 위험점수_정규화 (05 노트북)

### 절차

1. **Min-Max 스케일 (0~1)**  
   각 원시 지표를 구간 [0, 1]로 스케일합니다.  
   \( x_{\text{norm}} = (x - x_{\min}) / (x_{\max} - x_{\min}) \), max=min일 때는 0 처리.

2. **적용 대상 (5지표)**  
   - 격자내_어린이보호구역_어린이사고_건수  
   - 격자내_스쿨존_다발지_개수  
   - 격자내_미성년자_교통사고_건수  
   - 격자별_KSI  
   - **미성년자_유동** ← `격자_최종통합.csv`에서 join (노출량 차원 추가)

3. **가중 합산**  
   다섯 지표의 정규화값에 **균등 가중치 0.20**을 곱해 합산합니다.  
   → `위험점수_정규화` (0~1 구간)

### 가중치 산정 근거

| 지표 | 가중치 | 근거 |
|------|--------|------|
| 어린이보호구역 어린이사고 건수 | 0.20 | 스쿨존 내 실제 사고 — 법적 보호구역 안에서 발생한 사고로 정책 직결성 높음 |
| 스쿨존 다발지 개수 | 0.20 | 반복·집중 사고 구간 — 단순 1건 사고가 아닌 다발 패턴, 구조적 위험 반영 |
| 미성년자 교통사고 건수 | 0.20 | 전체 미성년자 사고 발생 빈도 — 노출 규모를 직접 반영하는 핵심 지표 |
| KSI (사망·중상자 수) | 0.20 | 사고 심각도 — 단순 건수가 아닌 인명 피해 수준을 보정하는 지표 |
| 미성년자 유동인구 | 0.20 | 실시간 노출량 — 격자 내 미성년자가 실제로 얼마나 통행하는지를 반영하는 수요 지표 |

> **균등 가중치(0.20×5) 채택 이유**  
> 다섯 지표는 각각 독립적인 위험 차원(발생 위치 / 패턴 / 빈도 / 심각도 / 노출량)을 측정하며,  
> 어느 하나가 다른 것보다 절대적으로 중요하다는 외부 근거(전문가 합의, 선행 연구 등)가 부재한 상태에서  
> 균등 가중치는 **편향을 최소화하는 보수적 기본값**으로 채택함.  
> 유동인구 추가로 "사고가 적더라도 미성년자가 많이 다니는 격자"의 잠재 위험을 포착할 수 있음.  
> AHP·전문가 설문 등 근거 확보 시 `05_정규화.ipynb` 내 가중치 변수를 조정하면 됨.

### 유동인구 데이터 연결

- 출처: `격자_최종통합.csv`의 `미성년자_유동` 컬럼 (API 기반 성연령별 유동인구에서 10세 미만 + 10~19세 합산)
- `05_정규화.ipynb` Cell 1에서 `격자_미성년자_분석.csv`와 gid 기준 left join 후 사용
- 유동 데이터 없는 격자(약 22%)는 0으로 fillna 처리 → 위험점수 과소평가 가능성 있으나, 데이터 부재 격자를 고위험으로 분류하는 것보다 보수적 접근이 적절함
