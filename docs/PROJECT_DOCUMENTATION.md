# LH 3기 신도시 미성년자 교통안전 분석 프로젝트 문서

## 📖 프로젝트 개요

본 프로젝트는 LH 3기 신도시 중 **하남교산**을 대상으로 미성년자(어린이·청소년) 교통안전 강화를 위한 데이터 기반 분석을 수행하였습니다. 4개 시·구(성남판교, 위례, 하남미사, 화성동탄)의 실제 교통사고 데이터를 분석하여 위험 패턴을 식별하고, 이를 하남교산 신도시에 전이하여 스마트 교통안전 시설의 설치 우선순위를 도출하였습니다.

### 🎯 프로젝트 목표
- 미성년자 교통사고 위험 요인 데이터 기반 식별
- 격자 단위 공간 분석을 통한 위험도 정량화
- 하남교산 신도시의 스마트 시설 설치 우선순위 도출
- 지역별 맞춤형 교통안전 대안 제시

## 🏗️ 분석 파이프라인 및 수행 절차

### 1단계: 데이터 전처리 및 기반 구축

#### 1.1 데이터 수집 및 정제
- **교통사고 데이터**: 미성년자 교통사고 발생 위치 및 시간 정보
- **격자 데이터**: 100m × 100m 공간 단위 분석 기반
- **토지이용 데이터**: 토지이용계획도(22·23년도) 기반 용도지역 정보
- **인구 데이터**: 미성년자 인구 밀도 및 분포 정보
- **시설 데이터**: 어린이보호구역, 스쿨존 다발지역 위치 정보

#### 1.2 공간 데이터 결합
```python
# 격자-토지이용 spatial join
격자_토지 = gpd.sjoin(격자, 토지이용, how='inner', predicate='intersects')

# 격자별 용도별 면적 비율 산출
격자별_비율 = 격자_토지.groupby(['gid', 'blockType']).size().unstack(fill_value=0)
격자별_비율 = 격자별_비율.div(격자별_비율.sum(axis=1), axis=0)
```

### 2단계: 탐색적 데이터 분석(EDA)

#### 2.1 토지이용 특성 분석 (01_토지이용_EDA.ipynb)
- **분석 내용**: 4개 기존 시·구 vs 하남교산 토지 구조 비교
- **주요 결과**: 
  - 4개 시·구: 5,337개 폴리곤, 88개 blockType
  - 하남교산: 761개 폴리곤
  - 도로 포함 격자: 4시·구 3,906개, 하남교산 490개

#### 2.2 교통량 및 도로망 분석 (02_도로망_교통량_EDA.ipynb)
- **분석 내용**: 도로망 데이터와 교통량(AADT) 결합 분석
- **핵심 파생변수**: 
  - `velocity_mean`: 격자별 평균 차량 속도
  - `AADT_mean`: 연평균 일교통량
  - `고부하_여부`: AADT 상위 25% 구간

#### 2.3 시간대별 노출 분석 (04_시간대별_노출_EDA.ipynb)
- **분석 내용**: 미성년자 등하교 시간대 유동인구 패턴 분석
- **주요 발견**: 등하교 시간대 미성년자 사고 35.8% 발생
- **핵심 파생변수**:
  - `통학로_노출_여부`: 통학로 경로 격자 여부
  - `등하교_유동_평균`: 등하교 시간대 유동인구

#### 2.4 기상 환경 분석 (05_기상_환경_EDA.ipynb)
- **분석 내용**: 기상 조건별 교통사고 특성 분석
- **주요 발견**: 
  - 야간 사고 37.1%
  - 악천후 사고 6.2%
  - 시인성 저하가 주요 위험 요인

### 3단계: 파생변수 생성 및 통합

#### 3.1 핵심 파생변수 정의
| 변수명 | 정의 | 산출 방식 | 활용 목적 |
|--------|------|-----------|-----------|
| 도로_비율 | 격자 내 도로 면적 비율 | 토지이용계획도 spatial join | 교통 발생 가능성 측정 |
| 주거_비율 | 격자 내 주거 시설 면적 비율 | 공동주택+단독주택 면적/격자 면적 | 미성년자 거주 밀도 추정 |
| 학교_비율 | 격자 내 교육시설 면적 비율 | 초·중·고등학교 면적/격자 면적 | 통학로 노출도 평가 |
| 위험점수_정규화 | 종합 교통위험도 점수 | 사고·인프라·환경 요인 가중합 | 격자별 위험 순위 결정 |

#### 3.2 데이터 통합 병합 (06_파생변수_통합_merge.ipynb)
```python
# 기준 테이블: 격자_미성년자_분석.csv (99,323개 격자)
통합 = 기준.copy()
통합 = 통합.merge(토지_파생변수, on='gid', how='left')
통합 = 통합.merge(교통_파생변수, on='gid', how='left')
통합 = 통합.merge(노출_파생변수, on='gid', how='left')

```

### 5단계: 설치 우선순위 도출

#### 5.1 우선순위 점수 산정 (07_하남교산_설치우선순위.ipynb)
```python
우선순위_점수 = (
    유사_고위험_여부 * 2 +           # 위험 전이 가중치
    도로_격자_여부 +                # 교통 발생 가능성
    학교_비율 * 3 +                 # 통학로 근접성 (가중치 3)
    유사도                          # 매칭 신뢰도
)
```
