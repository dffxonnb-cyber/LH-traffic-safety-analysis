# LH 3기 신도시 미성년자 교통안전 분석 프로젝트 문서

## 📋 프로젝트 개요

### 목표 및 배경
- 신도시 지역의 미성년자 교통사고 위험 요인 분석
- 데이터 기반의 맞춤형 안전 대안 제시
- 예산 효율성을 고려한 우선순위 산정

### 분석 범위
- **대상 지역**: 4개 신도시 + 하남교산
- **분석 단위**: 100m × 100m 공간 격자 (gid 기준)
- **데이터 기간**: 최근 3년간 교통사고 및 관련 데이터

## 🏗️ 분석 파이프라인 및 수행 절차

### 1단계: 데이터 수집 및 전처리
- 토지이용, 도로망, 교통량, 유동인구, 기상 데이터 수집
- 공간 좌표계 통일 (EPSG:4326)
- 격자별 데이터 연계를 위한 키 변수(gid) 생성

### 2단계: 탐색적 데이터 분석 (EDA)

#### 2.1 토지이용 분석 (01_토지이용_EDA.ipynb)
- **목적**: 격자별 토지이용 특성 파악 및 용도별 비율 도출
- **주요 분석**: 공간조인(gpd.sjoin), 면적 비율 계산
- **핵심 결과**: 도로_비율, 학교_비율, 주거_비율 변수 생성

#### 2.2 도로망·교통량 분석 (02_도로망_교통량_EDA.ipynb)
- **목적**: 교통량 패턴 분석 및 고부하 구간 식별
- **주요 분석**: AADT 집계, 속도 분석, 고부하 여부 판정
- **핵심 결과**: AADT_mean, 속도_mean, 고부하_여부 변수 생성

#### 2.3 시간대별 노출도 분석 (04_시간대별_노출도_EDA.ipynb)
- **목적**: 통학 시간대 유동인구 패턴 분석
- **주요 분석**: 등하교 시간대 유동인구 집계, 학교 인근 노출도 평가
- **핵심 결과**: 통학로_노출_여부, 노인시설_노출_여부, 등하교_유동_평균 변수 생성

#### 2.4 기상·환경 분석 (05_기상_환경_EDA.ipynb)
- **목적**: 기상 조건이 교통사고에 미치는 영향 분석
- **주요 분석**: 악천후/야간 사고 비율 분석
- **핵심 결과**: 악천후_여부, 야간_여부 변수 생성

### 3단계: 데이터 통합 및 파생변수 생성 (06_파생변수_통합_merge.ipynb)
- 각 EDA 결과물을 gid 기반으로 통합
- 총 20+ 개의 핵심 분석 변수 포함된 마스터 데이터셋 구축
- 결과물: 통합_격자_데이터.csv (4,521개 격자)

### 4단계: 하남교산 설치 우선순위 산정 (07_하남교산_설치우선순위.ipynb)
- 코사인 유사도 기반 위험 패턴 전이 분석
- 가중치 기반 우선순위 점수 산정
- 결과물: 하남교산_설치_우선순위.csv

### 5단계: 맞춤형 대안 제시 (08_맞춤형_대안_요약.ipynb)
- 격자 유형별 최적 안전 대안 제안
- 파레토 분석을 통한 예산 효율성 평가
- 정책 효과 시뮬레이션 및 제안
