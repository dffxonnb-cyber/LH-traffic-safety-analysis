# 적용대상지(하남교산)에 대한 분석 범위 설명

## 공모전 구분

- **분석대상지**: 4개 시·구 (경기 성남·화성·하남, 서울 송파) — 실제 데이터로 격자별 위험도·ARI·위험점수 산출
- **적용대상지**: 하남교산 — 공모전에서 “설치 위치 예측” 등을 적용할 지역으로 지정

## 하남교산 분석 방향 전환

하남교산에 대한 분석 기준을 **신도시 구분**이 아닌 **지형적·지리적 특성**으로 전환한다.

- **지형적 특성**: 산지·계곡·경사, 도로망 형상, 토지이용 구조(도로·주거·상업 비율) 등
- **교통축·접근성**: 주요 역·도로까지 거리, 도로 등급(road_rank), 교통량·혼잡 예측 가능 구간
- **적용 논리**: 4개 시·구에서 도출한 위험도·인프라 부족 패턴을 **유사한 토지·교통·지형 특성**을 가진 격자와 매칭하여 하남교산에 적용

토지이용계획도(23번), 도로망·교통량·혼잡 데이터, 격자 파일 등 보유 데이터를 활용해 하남교산 격자별 특성을 파악하고, 4개 시·구의 고위험 격자 특성과 유사한 구간을 식별하여 스마트 안전 시설 배치 우선순위를 도출한다.

## 현재 분석에서 하남교산을 격자 분석 대상에 넣지 않는 이유 (사고·시설 지표)

1. **데이터 범위**
   - 본 프로젝트에서 사용하는 **미성년자 교통사고**, **어린이보호구역 어린이사고**, **스쿨존 다발지** 등은 4개 시·구(또는 해당 권역) 중심으로 수집·제공된 데이터입니다.
   - **하남교산**은 적용대상지로 지정된 별도 권역이며, 아직 개발·정비 단계라 해당 지역 **내부**에 대한 위 시설·사고 기록이 공개 데이터상 **거의 없거나 없음**.

2. **격자 데이터만 있는 상태**
   - `data/격자_데이터/02._격자_(하남교산).geojson` 처럼 **하남교산 격자**는 제공되지만,
   - 하남교산 **안**에 매핑할 **미성년자 교통사고, 스쿨존 다발지, 어린이보호구역 어린이사고** 등 분석에 필요한 시설·사고 데이터가 사실상 없습니다.

3. **동일 지표 적용 시 결과**
   - 위와 같은 이유로, 4개 시·구와 “동일한 지표·로직”을 하남교산 격자에 적용하면 격자별 지표가 **전부 0에 수렴**합니다.
   - 따라서 “어느 격자를 우선할지”를 구분하는 **실질적인 설치 우선순위**를 도출할 수 없어, **노트북에서 하남교산 격자 분석(3지표·ARI·위험점수 산출) 단계는 수행하지 않습니다.**

## 정리

- **분석대상지(4개 시·구)**: 전처리·EDA·격자 집계(04)·정규화(05)까지 수행 → 위험도·고위험 격자·산출물 도출.
- **적용대상지(하남교산)**: 
  - 사고·시설 기반 격자별 3지표·ARI·위험점수 산출은 하남교산에 해당 데이터가 없어 **동일 로직으로는 수행하지 않음**.
  - **지형·토지이용·교통축 특성** 기반으로 토지이용계획도, 도로망·교통량·혼잡 데이터를 활용해 격자별 특성을 파악하고, 4개 시·구 고위험 격자와 유사한 특성을 가진 하남교산 격자를 식별하여 스마트 안전 시설 배치 우선순위를 도출한다.
