# 아이디어 확장 (지역 × 교통 × 취약계층)

**목표**: 지역 도메인(`regional_domain_summary`)과 설명 가능한 데이터 후보(`feature_engineering_plan` 3순위)를 연결해, **지역별 스토리 + 교통약자(어린이·노인)**를 엮는 아이디어를 정리한다. 공모전 해결·대안 제시 시 활용.

---

## 아이디어 일람

| № | 아이디어 한 줄 | 연결되는 지역 특성 | 필요한 데이터 |
|---|----------------|---------------------|----------------|
| 1 | **3호선 연장 개통 전제** → 하남교산 **남부 섹터**에 스마트 안전 시설 **선제 배치** | 위례 = 송파(오금)~하남교산 3호선 연장 구간. 2032 개통 시 유동·교통량 급증. 남부는 3호선·송파(위례) 연계. **지형·토지이용 기반** 남부 특성 파악. | 3호선 연장 노선·역 위치(공식 계획), 격자–역 거리, 기존 격자 위험도(격자_미성년자_분석 등). 토지이용(23번 하남교산). |
| 2 | **하남미사 패턴 이전** → 하남교산 **북부** 격자별 위험도·인프라 부족 구간을 미사 데이터로 보정·예측 | 하남미사 = 하남교산과 유사(3기·인접). 북부 = 5호선·하남미사 연계. **지형·도로망·토지 구조** 유사성 기반 매칭. | 격자_미성년자_분석(또는 노인)·인프라 부족 격자(06 산출물). 하남미사/교산 격자 gbn 매핑. 08·09·10 도로망·속도·교통량 격자 연동. |
| 3 | **강남·주요역 접근성 좋은 격자** → 통근·유동 많음 → **등하교 시간대(7~9시, 14~16시)**와 겹치는 구간에 교통량·속도 결합해 노출도 지표 산출 | 판교·위례·동탄 등 강남/환승역 접근성 차이. “접근성 좋음 = 유동·통근 수요 증가”. | 강남(역)·오금·하남시청 등까지 거리·대중교통 시간(맵/경기교통정보센터). 09·10 timeslot별 데이터와 격자 결합. 14~17 시설(학교 등)로 통학로 후보 격자 식별. |
| 4 | **신도시 시기별(2기·2.5기·3기)** 입주·인프라 성숙도 차이 → 동탄·판교 사례를 참고해 **하남교산(3기) 입주 단계별** 위험도·시설 투자 우선순위 시나리오 | 판교 2기, 동탄 2.5기, 하남미사·하남교산 3기. 시기별 공통·차이. | 시기별 입주·인프라 이력(문헌·보도). 격자별 위험도·인프라 밀도 시계열(있으면). 현재 격자_미성년자_분석·정규화로 “초기 단계” 가정 가능. |
| 5 | **도로 등급·평균속도 높은 격자 + 어린이·노인 시설 밀집** → **노출도·위험 시너지** → 스마트 안전 시설·스쿨존 강화 **우선 배치 후보** | 국도·지방도·고속도로(road_rank), 09 평균속도·10 추정교통량. 14~17 학교·어린이집·어린이보호구역. | 08 도로망(road_rank)·09·10·11·12 격자 연동. 14~17 시설 반경(500m 등) 내 격자 식별. 기존 위험점수·ARI(04·05 산출물)와 결합해 “고속도·고교통량·고위험” 격자 도출. |
