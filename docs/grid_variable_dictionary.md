# 4개 시구 격자 변수 정의서

## 개요

본 문서는 4개 시구(성남시, 하남시, 화성시, 송파구)의 100m × 100m 격자 단위 분석에 사용되는 모든 변수를 정의한다. 각 격자는 교통안전 위험도 평가 및 예측 모델의 기본 단위로 활용된다.

## 격자 기본 정보

| 변수명 | 타입 | 설명 | 데이터 소스 |
|--------|------|------|-----------|
| gid | 문자열 | 격자 고유 식별자 (예: 다사581304) | 격자 geojson |
| gbn | 문자열 | 시군구명 (경기도 성남시, 경기도 하남시, 경기도 화성시, 서울특별시 송파구) | 격자 geojson |

## 변수 산출 공식

### 위험점수 산출
```
위험점수 = (격자내_미성년자_교통사고_건수 × 가중치1) + 
          (격자별_KSI × 가중치2) + 
          (ARI × 가중치3) + 
          (등하교_유동_평균 × 가중치4)
```

### 우선순위 점수 산출 (하남교산)
```
우선순위_점수 = (유사_고위험_여부 × 2) + 
               (도로_격자_여부 × 1) + 
               (학교_비율 × 3) + 
               (유사도 × 1)
```

### 위험 유형 분류
- **A - 통학 위험**: 학교_비율 > 0 AND 도로_격자_여부 = 0
- **B - 도로 위험**: 학교_비율 = 0 AND 도로_격자_여부 = 1  
- **C - 복합 위험**: 학교_비율 > 0 AND 도로_격자_여부 = 1
- **D - 잠재 위험**: 학교_비율 = 0 AND 도로_격자_여부 = 0

## 데이터 연동 방식

### 공간 조인 기준
- **좌표계**: EPSG:5179 → WGS84 변환
- **매핑 방식**: 최근접 이웃 (Nearest Neighbor)
- **거리 기준**: 500m 반경 (max_dist_deg = 0.0055)
- **연동 키**: gid (격자 고유 식별자)

### 데이터 통합 순서
1. 기본 격자 정보 (gid, gbn)
2. 사고 변수 통합
3. 토지이용 변수 병합
4. 교통량 변수 연동
5. API 유동인구 데이터 매핑
6. FRIN/TI 지표 연동
7. 파생 변수 산출

## 품질 관리 기준

### 결측치 처리
- 교통 변수: 0으로 대체 (도로 없는 격자)
- 유동 변수: 0으로 대체 (데이터 없는 지역)
- 토지이용 변수: 0으로 대체 (해당 용도 없음)

### 이상치 처리
- 속도 데이터: 0-200km/h 범위로 제한
- 유동인구: 상위 1% 값으로 상한 설정
- 사고 건수: 음수 값 제거

### 연동 성공률 기준
- 유동인구: 80% 이상 연동 성공
- 교통사고: 95% 이상 연동 성공
- FRIN/TI: 80% 이상 연동 성공

## 활용 방안

### 위험도 예측 모델
- **입력 변수**: 사고, 유동, 교통, 토지이용 변수
- **타겟 변수**: 위험점수_정규화
- **모델 종류**: 회귀분석, 랜덤포레스트, XGBoost

### 시설 설치 우선순위
- **주요 변수**: 위험점수, 유사_고위험_여부, 도로_격자_여부, 학교_비율
- **산출 방식**: 가중치 조합 및 순위 부여

### 지역별 맞춤형 대안
- **분류 기준**: 위험_유형, 취약_유형, 시군구 특성
- **대안 수립**: 시설물 종류, 설치 위치, 우선순위

| 기술 | 파라미터 | 목적 |

### 인프라 데이터 원본

| 가드펜스 | 도로 시설물 데이터 | 격자내_가드펜스_수 | 물리적 보호시설 |

### 인프라 공백 판정 기준
| 구분 | 판정 조건 | 공백_여부 산출 | 의미 |
|------|----------|---------------|------|
| 완전_공백 | 횡단보도=0 AND CCTV=0 | 1 | 기본 보호 인프라 없음 |
| 부분_공백 | 횡단보도=0 OR CCTV=0 | 1 | 일부 인프라 부족 |
| 인프라_보유 | 횡단보도>0 AND CCTV>0 | 0 | 기본 인프라 갖춤 |

### 인프라 변수 산출 공식
```python
# 기본 인프라 공백 여부
인프라_공백_여부 = np.where(
    (횡단보도_수 == 0) | (CCTV_수 == 0), 1, 0
)

# 고위험 격자 내 인프라 공백
고위험_인프라_공백 = np.where(
    (고위험_여부 == 1) & (인프라_공백_여부 == 1), 1, 0
)

# 스쿨존 연계 인프라
스쿨존_인프라_여부 = np.where(
    (스쿨존_수 > 0) & ((횡단보도_수 > 0) | (CCTV_수 > 0)), 1, 0
)
```
