# LH 신도시 교통안전 분석 (미성년자 격자 위험도)

**(LH) 신도시 교통 인프라 데이터 분석을 통한 3기신도시 어린이 등 취약계층 교통안전 대안제시 공모전**  
- **분석 대상**: 4개 시·구 (경기 성남·화성·하남, 서울 송파)  
- **적용 대상**: 하남교산 — **지형·토지이용·교통축 특성** 기반 분석 (신도시 기준 아님). 사고·시설 지표는 4개 시·구만 산출 ([적용대상지_하남교산_설명.md](적용대상지_하남교산_설명.md) 참고)

---

## 목적

100×100m 격자 단위로 **미성년자(12세 이하 + 13~20세)** 교통사고, 어린이보호구역 어린이사고, 스쿨존 다발지를 매핑하고, **위험점수**·**ARI(Accident Risk Index)** 를 산출해 고위험 격자를 식별합니다.
