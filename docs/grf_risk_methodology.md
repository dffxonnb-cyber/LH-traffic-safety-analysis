# 공간 좌표 포함 Random Forest 기반 위험지수·점수 산출 근거

본 문서는 격자별 **공간 RF 예측 위험지수**, **공간 RF 위험점수_정규화**의 정의와 **논리적·정책적 근거**를 정리한 것입니다.
관련 노트북: `research_notebooks/gwrf_analysis/`, `analysis_pipeline/05_grf_feature_integration.ipynb`

> **용어 주의:** 파일명과 일부 기존 컬럼의 `GRF`·`GWRF`는 과거 프로젝트 명칭을 보존한 legacy label입니다. 공개 저장소에서 확인되는 핵심 구현은 **공간 좌표를 피처로 포함한 scikit-learn Random Forest**이며, 전용 geographically weighted random forest 구현을 뜻하지 않습니다.

**취약계층(관측 기반) 지표와의 구분**: `risk_index_methodology.md`의 위험점수·ARI·위험점수_정규화는 **실제 사고·KSI·다발지·유동** 등 관측값의 가중 합이다. 공간 RF 지표는 **도로·교통·인프라·유동·공간 좌표**로 **사고 발생을 예측한 모델의 예측값**을 위험지수로 사용하며, **사고 이력이 없는 격자**(신도시·무사고 구간)에도 적용할 수 있다.

## 0. 공간 좌표 포함 Random Forest를 쓰는 논리적 필요성

| 단계 | 논리 |
|------|------|
| **목표** | 사고 이력이 부족한 대상지에서 **위험 신호를 비교**하고, 현장 검토가 필요한 우선 후보를 제시해야 함. |
| **관측 기반의 한계** | 위험점수·ARI는 **과거 사고·KSI·다발지**가 있어야 산출 가능함. **신도시·개발 예정지·무사고 구간**에는 해당 데이터가 없거나 짧아 관측 기반 지표를 쓸 수 없음. |
| **정책 요구** | 도로교통법 시행규칙 별표 8의2는 위험지수 산정 시 **사고·도로 조건·보행 조건 등을 종합 평가**하도록 함[^1]. 즉 “사고만 보지 말고 **도로·교통·시설·노출**을 함께 보라”는 방향과 부합해야 함. |
| **결론** | **환경 요인(도로·교통·인프라·유동)** 으로 “해당 환경에서 기대되는 사고 수준”을 **예측**해 위험지수로 쓰면, (1) 사고 이력이 없는 곳에도 적용 가능하고, (2) 정책상 “종합 평가” 요구에 맞추며, (3) 검토 우선순위와 가정 기반 시나리오 비교의 기준이 됨. |

따라서 **공간 RF 예측 위험지수**는 “관측 기반을 보완하는 **예측 기반** 위험 지표”로, 선제적 현장 검토와 입지 논의의 우선순위를 지원하기 위해 도입한 것이다.

## 1. 공간 RF 예측 위험지수

### 정의

**공간 RF 예측 위험지수** = 격자별 **사고 건수**(또는 그에 준하는 위험 수준)를, **도로·교통·인프라·유동·공간 좌표** 등 위험 요인으로 학습한 Random Forest의 **예측값**(연속형).

- **타깃(예측 대상)**: `acc_count`(격자 내 교통사고 건수) 또는 `격자내_미성년자_교통사고_건수`
- **피처(설명 변수)**: 도로_비율, 주거_비율, 상업_비율, 학교_비율, 녹지_비율, velocity_mean, AADT_mean, FRIN_mean, TI_mean, 미성년자_유동, 노인_유동, 등하교_유동_평균 등 (데이터 존재 시)

### 타깃을 사고 건수로 둔 근거

| 근거 | 설명 |
|------|------|
| **지표 해석의 일관성** | 기존 ARI·위험점수는 모두 “사고 수준”(건수·KSI·다발지 등)을 한 축으로 함. 예측 타깃도 **사고 건수**로 두면, “이 격자는 관측 기준으로 X, 예측 기준으로 Y”처럼 **동일 차원**에서 비교·통합 가능하며, 정책 담당자 해석이 일관됨. |
| **법령·정책과의 정합성** | 도로교통법 시행규칙 별표 8의2는 어린이보호구역 내 무인 교통단속용 장비 설치 시 **ARI(교통사고 위험지수)** 산정에 사고·도로 조건 등을 **종합 평가**하도록 규정함[^1]. 본 분석은 “사고 건수”를 **직접 관측이 아닌, 도로·교통·시설·노출 요인으로 추정한 값**으로 정의하여, 동일한 “위험지수” 개념 아래 **예측 기반** 버전을 둔 것이다. |
| **시나리오 비교와의 연결** | 위험 수준을 **사고 건수 또는 그에 준하는 연속값**으로 두면, 가정한 감소율을 적용한 전후 시나리오를 같은 척도에서 비교할 수 있다. 이는 실측 사고 감소량이나 인과효과가 아니다. |

### 피처를 도로·교통·인프라·유동으로 둔 근거

| 근거 | 설명 |
|------|------|
| **법령상 종합 평가 항목과의 대응** | 별표 8의2가 요구하는 “사고·도로 조건·보행 조건 등”을 격자 단위로 구현할 때, **도로_비율**(도로 조건), **AADT·velocity**(교통량·속도), **FRIN·TI**(도로 기능·교통 지표), **미성년자_유동·등하교_유동**(보행·노출) 등이 각각 대응함. 즉 **종합 평가에 포함되는 요인**을 가용 격자 변수로 매핑한 것이다. |
| **교통사고 예측 연구와의 정합성** | 교통사고 발생·공간 회귀 연구에서는 **도로 특성, 교통량(AADT), 속도, 시설 유무, 유동인구(특히 어린이·노인)** 등이 사고와 유의미한 연관을 보인다고 보고됨. 본 프로젝트의 피처는 해당 요인들에 대응하는 컬럼만 선별한 것이며, **선행 연구에서 제시한 위험 요인**을 반영한다는 근거를 가짐. |
| **데이터 가용성** | 격자_최종통합 등 프로젝트 내 가용 데이터에 존재하는 변수만 사용하여, **재현 가능성**과 **검증 가능성**을 확보함. |

### 예측값을 위험지수로 쓰는 이유

- **사고 이력 부재 구간의 처리**: 신도시·개발 예정지·무사고 구간에서는 관측 기반 위험점수·ARI를 산출할 수 없다. **환경 요인만으로** “이 환경이라면 통계적으로 기대되는 사고 수준”을 추정하면, **사전에** 위험 잠재력을 논의하고 현장 점검 후보를 정하는 참고 근거로 쓸 수 있다.
- **“기록 부재”와 “안전”의 구분**: 어떤 격자에 사고 기록이 적은 것이 **환경이 안전해서**인지, 단순히 **이력이 짧거나 통행량이 적어서**인지 구분하려면, **동일한 환경 요인으로 학습한 모델의 예측값**을 “해당 환경에서 기대되는 사고 수준”으로 해석하는 것이 타당하다. 예측값이 높으면 “환경상 위험 잠재력이 크다”로, 낮으면 “상대적으로 낮다”로 해석할 수 있다.
- **시나리오 비교의 전제**: “설치 전 위험도”를 **숫자**로 두어야, 감소율을 적용한 시나리오 변화를 계산할 수 있다. 관측 기반 지표가 없는 구간에서는 **공간 RF 예측 위험지수**가 그 역할을 한다. 이 값은 실제 사고 감소 효과가 아니라 검토용 시나리오 기준이다.

### 모델 방식

- **공간 좌표 포함 Random Forest 위험 모델**: 프로젝트 내에서는 **Random Forest 회귀**로 타깃(사고 건수)을 예측하며, 필요 시 **log1p** 변환 후 예측·**expm1** 역변환하여 격자별 예측 위험지수로 사용함. 공개 검증 패키지의 LORO AUC·Lift는 사고 발생 여부를 타깃으로 한 Random Forest 분류 모델에서 계산함.
  - **RF를 쓰는 이유**: (1) 비선형·변수 간 상호작용을 흡수할 수 있고, (2) 변수 중요도 등으로 **해석 가능성**을 확보할 수 있으며, (3) 공간 좌표를 포함해 위치별 패턴을 학습할 수 있음.
  - 외부 `mg_gwrf_results.csv` 같은 파일을 사용하는 실험 경로는 별도로 존재할 수 있으나, 해당 파일이 공개 저장소에 없으면 실제 전용 GWRF 구현 여부는 `needs confirmation`이다.
- **이전 가능성 검증**: 다른 지역으로 학습한 모델을 적용 대상지에 쓰는 것이 타당한지는 **LORO(Leave-One-Region-Out)** 로 검증함. 한 지역을 제외하고 나머지 지역에서 학습한 뒤 홀드아웃 지역에서 AUC와 Top-10% Lift를 확인한다.

## 2. 공간 RF 위험점수_정규화

### 정의

**공간 RF 위험점수_정규화** = 공간 RF 예측 위험지수를 **Min-Max 스케일**로 [0, 1] 구간에 맞춘 값. 기존 데이터 컬럼에는 legacy 명칭인 `GRF 위험점수_정규화`가 남아 있을 수 있다.

- \( x_{\text{norm}} = (x - x_{\min}) / (x_{\max} - x_{\min}) \), max=min일 때는 0 처리.

### Min-Max(0~1)를 쓰는 근거

| 근거 | 설명 |
|------|------|
| **기존 지표와 스케일 통일** | `risk_index_methodology.md`의 **위험점수_정규화**도 Min-Max 0~1로 산출함. 공간 RF 지표도 동일한 0~1 스케일로 두면, 취약계층 위험점수_정규화와 **비교·병렬 활용·우선순위** 논의 시 해석이 일관되며, “관측 기반 점수”와 “예측 기반 점수”를 같은 척도에서 논의할 수 있음. |
| **해석 용이성** | 격자 간 상대적 위험 비교·순위·시각화 시 0~1 구간이 직관적이며, “상위 20% 고위험” 등 구간 설정도 동일한 방식으로 적용 가능함. |
| **보조 지표** | 이상치에 강한 **퍼센타일·로버스트 Min-Max** 등은 `grf_보강/GRF_보강_통합.ipynb`에서 검토용으로 산출하며, 기본 비교·정책 논의용으로는 기존 방식과 동일한 **Min-Max 0~1**을 기준으로 둠. |
