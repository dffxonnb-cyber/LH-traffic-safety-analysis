# Insight Analysis

**목적**: 원혁님 API 데이터 + 기존 분석 결과를 결합해 획기적 인사이트 도출 및 시각화.  
**기간**: Day 1~7 (일별 진행)

## 노트북 실행 순서

1. `01_API_격자_연동.ipynb` — **(Day 1, 선행 필수)** 원혁님 API → gid 연동, `격자_최종통합.csv` 생성
2. `02_인프라공백_고위험.ipynb` — (Day 2) 인사이트 A: 인프라 없는 고위험 격자
3. `03_동시취약_시간대.ipynb` — (Day 3) 인사이트 B: 미성년자·노인 동시 취약 × 시간대
4. `04_하남교산_인프라예측.ipynb` — (Day 4) 인사이트 C: 하남교산 유사격자 인프라 비교
5. `05_종합_인사이트.ipynb` — (Day 6) 전체 종합 지도 + 시설물 매트릭스

## 핵심 인사이트 3개

| 인사이트 | 핵심 메시지 | 데이터 근거 |
|---|---|---|
| **A** | "고위험 격자 상당수에 보호 인프라가 없다" | 위험점수 + 횡단보도/CCTV 현황 |
| **B** | "오후 2~4시, 미성년자·노인이 같은 격자에 동시 노출" | 시간대 사고 분포 + 격자 유형 분류 |
| **C** | "하남교산 유사격자가 4시·구에서 어떤 인프라 현황인가" | 유사격자 매칭 + 인프라 비교 |
